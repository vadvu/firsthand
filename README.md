# Из первых рук

Надоело узнавать про своих друзей и близких из новостей, а не из первых рук? 
Тогда это приложение специально для вас: оно проверяет всех ваших близких на предмет внесения в перечень 
иностранных агентов, террористов и экстремистов. 
Список лиц, в отношении которых применяются временные ограничительные меры, 
пока что не добавлен из-за его халатной малочисленности.

Приложение работает на R.

## Установка

Нужны [R](https://cran.r-project.org/) версии 4.2 или новее и [Git](https://git-scm.com/install/).

Если Git ещё не установлен:

- **macOS:** выполните в терминале `xcode-select --install` и завершите установку
  [Command Line Tools](https://git-scm.com/install/mac).
- **Windows:** выполните в PowerShell `winget install --id Git.Git -e --source winget`
  или скачайте и запустите [установщик Git for Windows](https://git-scm.com/install/windows).

После установки откройте терминал заново и проверьте Git командой `git --version`.

Дальше скачиваем и делаем установку в терминале:

```sh
git clone https://github.com/vadvu/firsthand.git firsthand
cd firsthand
Rscript install.R
```

В Windows, если Rscript не найден в PATH, выполните вместо последней строки:

```powershell
.\firsthand.cmd setup
```

Установка добавит команду `firsthand` в терминал, ссылающуюся на эту
папку.

## Функционал

```sh
firsthand                  # запуск, открыть меню

firsthand edit             # изменить список в терминале
firsthand refresh          # скачать и обработать оба реестра
firsthand check            # обновить реестры и проверить список
firsthand check --cached   # проверить по сохранённым таблицам без сети
firsthand watchlist        # показать список людей
firsthand tables           # показать, где лежат CSV
firsthand help             # справка
```

В редакторе: `+ ФИО` добавляет человека, `- 2` удаляет строку №2, `s` сохраняет,
`q` отменяет изменения. Фамилия должна идти первой. Поддерживаются фамилии и
полные ФИО.

Список находится в `watchlist.txt`. Комментарии с `#` и пустые строки игнорируются.
Если нужен CSV с датами рождения и альтернативными именами:

```csv
name,birth_date,aliases
Петров Пётр Петрович,1980-01-15,Прежнев Пётр Петрович
```

Вызов: `firsthand check --watchlist watchlist.csv`. Даты — `YYYY-MM-DD` или
`DD.MM.YYYY`, альтернативы разделяются `|`. Терминальный редактор работает с TXT;
CSV можно редактировать в табличном редакторе. Инициалы не поддерживаются.

## Что сохраняется

В папке `output` после успешного обновления только две таблицы:

- `foreign_agents.csv` — физические лица из реестра Минюста;
- `terrorists_extremists.csv` — физические лица из обеих частей перечня Росфинмониторинга.

Таблицы заменяются при обновлении. Результаты проверки и изменения показываются в терминале.

Небольшая служебная база сравнения, блокировка и логи расписания находятся в `.state/`. 


## Чтобы работало как часы

Можно поставить самообновление реестра

```sh
firsthand schedule --every-hours 168 --install
firsthand unschedule
```

Для ежедневной проверки замените `168` на `24`. Без `--install` только создаётся
файл задания в `.state/`. Используются launchd на Mac и Планировщик заданий Windows;
для работы нужны пользовательский сеанс, файлы приложения и интернет.
